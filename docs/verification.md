## 安全与隐私

- 公开构建固定 provider=mock，真实请求函数有额外拦截；构建不读取本机环境文件。
- 上传衣物图、个人资料、保存方案和社区演示帖子仅保存在当前浏览器，不上传后台，也不对其他访客可见。避免上传私人照片。
- 公开仓库不包含 .env、API 密钥、node_modules、本机缓存或私人用户数据。
- 本机 AI 代理仅用于个人联调，不能直接作为公共付费网关。真实模型公开版仍需鉴权、配额、预算与滥用防护。
- 没有 service worker，不声称离线可用；网络和 GitHub Pages 可达性仍取决于访问者所在环境。
