先用已有衣服

预置演示单品，无需注册或录入整套衣橱即可开始体验。

用 60 秒体验关键流程

  1. 工作室选择“面试”、22°C，生成三套演示搭配。
  2. 将温度改为 15°C，查看完整性与外套规则；保存一套方案。
  3. 打开“我的” → “我的方案”，验证查看、保存与删除闭环。
  4. 到衣橱体验图片选择与确认入库；演示识别不表示模型实际理解了图片。

三个关键产品取舍

先确认，再入库

模型识别有不确定性，保留人工修正名称、品类、颜色与季节的步骤。

硬规则与审美分开

缺鞋、缺下装、温度外套约束可程序校验；审美与身材适配仍需真人评测。

让失败可见

校验失败重试一次，再失败明确降级；区分实际来源与配置的服务名称。
